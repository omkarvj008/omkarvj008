## 🔷 Palantir Foundry & Ontology

- **Ontology design** – modelling object types, properties, link types and action types that map business entities (SKUs, suppliers, purchase orders, warehouses, stores) into a shared semantic layer
- **Data integration & pipelines** – Data Connection syncs from ERP and SQL sources; transforms in Pipeline Builder and Code Repositories (Python / PySpark), with schedules, incremental builds and data health checks
- **Ontology-backed applications** – operational apps and dashboards in Workshop, Slate and Quiver; ad-hoc analysis in Contour
- **Functions & Actions** – business logic with Functions on Objects (TypeScript / Python) and Action types for governed writeback and decision capture
- **AIP** – AIP Logic and LLM-powered workflows built on top of the Ontology
- **Governance** – data lineage, permissions and markings, and branching for safe, version-controlled releases
